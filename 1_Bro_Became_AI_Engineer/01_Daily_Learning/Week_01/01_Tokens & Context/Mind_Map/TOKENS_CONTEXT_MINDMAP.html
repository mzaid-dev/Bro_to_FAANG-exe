Token Fundamentals

What it is

A token is a model-specific processing unit: word, subword, punctuation, whitespace, Unicode piece, or special marker.

Why it matters
  • Drives context usage and cost
  • Same text can count differently across models
  • Character count is only a heuristic
Token ≠ word ≠ character ≠ byte.
2

Context & Memory

What it is

Context is temporary information available during the current generation.

Separate systems
  • Model weights → trained knowledge
  • Context → visible now
  • Data store → durable history
  • Vector store / RAG → retrieve evidence
Stored ≠ visible to the model.
3

Context Budget

Request anatomy

Input = System + Tools + History + Retrieval + User + Overhead

Safe input

Respect product limit, provider limit, reserved output, and safety buffer.

  • Reserve output before filling context
  • Keep product limits explicit
  • Estimate cost before provider call
Count the complete request—not only the user message.
4

When Context Does Not Fit

Options
  • Reject
  • Chunk
  • Compact / summarize
  • Retrieve / RAG
  • Remove unused tools
  • Route to larger-context model
Silent truncation is almost never the right default.
5

Long Context vs RAG

Long context

Capacity: more material can fit in one request.

RAG

Selection: retrieve focused evidence from a large knowledge source.

  • Compare quality, latency, cost, privacy
  • Retrieval can fail
  • More context can dilute relevance
Long Context = Capacity · RAG = Evidence Selection.
6

Performance & Security

Performance
  • More input → more prefill / TTFT / cost
  • More output → more decode time / cost
  • Streaming improves perceived responsiveness
Security
  • Denial of wallet
  • Data minimization
  • Bounded retries / quotas / rate limits
Token budgeting does not solve prompt injection.
7

Clean Architecture

Ownership
  • Domain → budget rules
  • Application → assess request
  • Port → TokenCounter contract
  • Infrastructure → provider-specific counting
  • Delivery → CLI / API
Business rules know abstractions—not provider SDKs.
