## Evidence Lifecycle

```mermaid
stateDiagram-v2
    [*] --> STUDIED
    STUDIED --> IMPLEMENTED
    IMPLEMENTED --> VERIFIED
    VERIFIED --> RELEASED
    RELEASED --> IMPROVED
    IMPROVED --> VERIFIED
```

| Stage | Meaning |
|---|---|
| **STUDIED** | Concepts, requirements, constraints, and architecture decisions are understood and documented. |
| **IMPLEMENTED** | Planned capabilities are developed and integrated into the system. |
| **VERIFIED** | Testing, evaluation, security validation, and reproducibility evidence are completed. |
| **RELEASED** | A documented version is published with release notes, usage instructions, and demonstration evidence. |
| **IMPROVED** | Future roadmap improvements extend the system while preserving existing contracts and reliability. |
